# ☕ Café Sales Analysis Dashboard | Excel

## 📌 Project Overview

This project focuses on analyzing café sales data using **Microsoft Excel** to identify sales trends, customer purchasing patterns, product performance, and revenue insights.

The dataset was cleaned and prepared by handling missing values, `UNKNOWN` and `ERROR` entries, and inconsistent data before building interactive dashboards using PivotTables, PivotCharts, and Excel visualizations.

## 🎯 Project Objectives

- Analyze overall café sales and revenue performance.
- Identify the best-performing products.
- Understand payment method distribution.
- Compare sales across different store locations.
- Explore sales trends over time.
- Transform raw data into meaningful business insights.
- Support data-driven business decisions through interactive dashboards.

## 📂 Dataset Description

The dataset contains café transaction records with the following columns:

| Column | Description |
|---|---|
| Transaction ID | Unique transaction identifier |
| Item | Product purchased |
| Quantity | Number of units purchased |
| Price Per Unit | Price of each unit |
| Total Spent | Total transaction amount |
| Payment Method | Method used for payment |
| Location | Café transaction location |
| Transaction Date | Date of the transaction |

## 🧹 Data Cleaning & Preparation

The raw dataset contained missing values, `UNKNOWN` and `ERROR` entries, and inconsistent records.

The following steps were performed:

- Identified missing and invalid values.
- Replaced missing, `UNKNOWN`, and `ERROR` entries with null values.
- Cleaned inconsistent text entries and removed unnecessary spaces.
- Checked numeric columns and date formats.
- Prepared the dataset for analysis using Excel.
- Preserved the transaction records while cleaning the data.

**Note:** Null values were retained where information was unavailable rather than inventing replacement values.
